Prescripto — Doctor Appointment Booking

A complete healthcare booking platform featuring patient, doctor, and admin dashboards with secure authentication, Stripe & Razorpay payment integration, appointment scheduling, and responsive dashboards.

GitHub ↗ Live Demo ↗
prescripto.vercel.app

Overview

Prescripto is a three-sided marketplace for booking doctor appointments: patients search and book, doctors manage their schedule and consultations, and admins run the platform. It's built as a real product, not a demo — with actual payment processing, protected routes per role, and dashboards that respond to what's actually happening in the database.

Features

  • Separate patient, doctor, and admin dashboards with role-based access
  • Secure authentication and session handling
  • Live payment processing through Stripe and Razorpay
  • Appointment scheduling with doctor availability
  • Fully responsive layouts across all three dashboards

Technology stack

React Node.js Express MongoDB Stripe Razorpay

Challenges

  • Keeping three different dashboards consistent while each needed different permissions and data shapes
  • Reconciling two payment providers (Stripe and Razorpay) behind one booking flow
  • Modeling appointment scheduling so doctor availability, time zones, and double-bookings stayed correct
