AI Interview Mocker

Generate interview questions based on job role and receive instant AI feedback powered by Google Gemini.

GitHub ↗ Live Demo ↗
ai-interview-mocker-aplr-alpha.vercel.app

Overview

AI Interview Mocker takes a job role as input and generates a tailored set of interview questions, then scores the candidate's spoken or typed answers with feedback generated by Gemini. It's built to feel like a low-stakes practice partner rather than a form.

Features

  • Role-specific question generation on demand
  • Instant AI-scored feedback on each answer
  • Session history so a candidate can track improvement over time

Technology stack

Next.js Gemini API

Challenges

  • Prompting Gemini for consistently structured, role-relevant questions rather than generic ones
  • Turning free-form model feedback into a UI that reads as coaching, not a wall of text
